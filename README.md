<h1> Projects on Data Cleaning </h1>

These are some small projects on data cleaning following walkthroughs on Youtube to improve my data cleaning skills.

Tools used: VS Code, MS SQL, and the Jupyter Notebook extension.

1. [Onur Baltaci's Data Cleaning with Python](https://youtu.be/I7DZP4rVQOU?si=QERP2cgwvcXKeNA2)

- **Airbnb Open Data Cleaning using Python**  
  Cleans and standardizes Airbnb listing data in Python, producing a structured dataset ready for analysis.
- [Dataset](https://www.kaggle.com/datasets/arianazmoudeh/airbnbopendata)

2. [Lore So What's Watch me Cleaning Data in minutes with SQL](https://youtu.be/voWe8feyvp0?si=kjIJ1k8R7XdWVxR7)

- **Shipments Data Cleaning using SQL**  
  Uses SQL to identify and correct inconsistent shipment records, then exports a cleaned dataset for further use.
- [Dataset](https://drive.google.com/file/d/1P0IqNZZ6oc85h303tmLeOn2gw18-HsVS/view?usp=drive_link)
